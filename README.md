## 🧠 STEM University Sentiment Analysis
**NLP · BERT · DistilBERT · Transformers · Reddit Data**
Analyzed student sentiment across leading U.S. engineering universities using traditional NLP and transformer-based architectures.
- 💬 **5,735 Reddit posts**
- 🏫 **16 U.S. engineering universities**
- 🤖 Compared **TF-IDF + Logistic Regression, BERT & DistilBERT**
- 📈 BERT achieved **84.5% test accuracy**
- ⚡ DistilBERT achieved approximately **85% validation accuracy**

**Graph Neural Networks · GAT · PyTorch · Sports Analytics**
Built a graph-based machine learning system to identify football legends using player performance and teammate-network information.
- ⚽ **3,277 player nodes**

- 📅 **16 seasons** of Premier League & La Liga data

## 🍎 Food Affordability, Health & Healthcare Cost Prediction
**Machine Learning · Autoencoders · XGBoost · SHAP · Causal Inference · EconML**
Built a county-level machine learning and causal inference framework to study relationships between food affordability, health outcomes and Medicare spending.
- 🇺🇸 Approximately **3,100 U.S. counties**
- 🗂️ Integrated **9 public data sources**
- 🧠 Used **Autoencoders & PCA** for representation learning
- 🌳 Applied **XGBoost and spatial machine learning**
- 🔍 Model interpretation using **SHAP**
- 📊 Causal inference using **Double Machine Learning via EconML**
- 💵 Identified a **$3.50/meal policy tipping point**
- 🏥 Simulated **$2.4B+ potential annual Medicare savings**

## 🌍 Multilingual Machine Translation Quality Estimation
**Multilingual NLP · XLM-RoBERTa · LaBSE · Transformers · Regression**
Developed a multilingual framework for estimating machine-translation quality **without requiring reference translations**.
- 🌎 Evaluated **English–German, Romanian–English & Sinhala–English**
- 🧠 Used **LaBSE and XLM-RoBERTa embeddings**
- 📊 Engineered linguistic, similarity and embedding-based features
- 🤖 Compared **8+ regression models**
- 🔬 Fine-tuned **XLM-RoBERTa** for quality estimation
- 📈 Evaluated using **Pearson/Spearman correlation, RMSE & MAE**
